# AI 智能数据分析助手

基于 Python、Streamlit 和大语言模型构建的交互式数据分析工具。用户可以上传 CSV 数据文件，通过自然语言提出分析需求，获取数据分析结果、表格或可视化图表。

## 项目简介

本项目尝试将大语言模型与 Pandas 数据处理能力结合，降低数据分析的使用门槛。用户无需手动编写复杂的分析代码，即可通过自然语言探索数据、查看统计结果并生成图表。

项目以模拟电商订单数据为例，验证自然语言数据分析流程。

## 功能特性

* **CSV 数据上传**：支持上传 CSV 文件并预览原始数据。
* **自然语言问答**：输入业务问题，调用大语言模型完成数据分析。
* **数据结果展示**：根据模型返回结果展示分析结论和表格。
* **图表生成**：支持柱状图、折线图和散点图。
* **交互式操作**：通过 Streamlit 页面完成数据上传、问题输入和结果查看。

## 运行方法

### 1. 环境准备

建议使用 Python 虚拟环境运行项目。

克隆仓库：

```bash
git clone https://github.com/sandywei1998/ai-data-analysis-assistant.git
cd ai-data-analysis-assistant
```

创建并激活虚拟环境：

Windows：

```bash
python -m venv .venv
.venv\Scripts\activate
```

安装项目依赖：

```bash
pip install -r requirements.txt
```

### 2. 配置 API Key

项目需要配置智谱 AI API Key。

运行应用后，在页面侧边栏的 API 密钥输入框中填写有效的 API Key。请勿将真实 API Key 写入代码或提交到公开仓库。

### 3. 启动应用

```bash
streamlit run main.py
```

启动后，根据终端输出的本地地址打开应用，在页面上传 CSV 文件并输入分析问题。

## 示例分析场景

使用仓库中的 `ecommerce_orders_demo.csv`，可以尝试以下问题：

* 各产品的销售额分别是多少？
* 哪些商品的利润最高？
* 不同城市的销售表现有什么差异？
* 如何根据订单数据生成趋势图？
* 根据当前数据进行汇总和对比分析。

实际分析结果取决于上传的数据、问题描述和模型输出。

## 开发与调试记录

开发过程中，针对大语言模型输出与 Python 数据处理之间的衔接，进行了以下调试与改进：

* **统一图表数据结构**：针对模型返回的一维数据与二维表格结构不一致导致的 DataFrame 构建异常，调整图表数据处理逻辑。
* **处理模型返回格式差异**：针对模型可能使用 Markdown 代码块包裹 JSON 的情况，在解析前增加格式清理步骤，降低 JSON 解析失败的风险。
* **完善自然语言分析流程**：通过模拟电商订单数据测试多种分析问题，检查模型结果解析、表格展示与图表生成流程。

这些改进帮助提升了模型输出与应用程序之间的数据交互稳定性，但并不意味着模型对所有问题都能保证准确回答。

## 项目说明
